# ==================================================================
# Pasos para iniciar la simulación del robot en el almacén con ROS2
# ==================================================================

# Nota: Ejecuta todos los comandos desde una nueva terminal, y asegúrate
# de estar en el directorio raíz de tu proyecto.

# ------------------------------------------------------------------
# Paso 1: Navegar al directorio del workspace
# ------------------------------------------------------------------
# Asegúrate de que tu terminal esté en la carpeta principal del proyecto.

cd /home/kishouandrea/Github-projects/gazebo-fortress

# ------------------------------------------------------------------
# Paso 2: Compilar el workspace (Opcional si no hay cambios)
# ------------------------------------------------------------------
# Este comando compila los paquetes necesarios. Si no has hecho cambios
# en el código, puedes saltártelo, pero es buena práctica ejecutarlo.

colcon build --packages-select rb_theron_description_fortress

# ------------------------------------------------------------------
# Paso 3: Configurar el entorno de la terminal (¡MUY IMPORTANTE!)
# ------------------------------------------------------------------
# Este comando le dice a tu terminal dónde encontrar los paquetes de ROS2
# que acabas de compilar. Debes ejecutarlo en CADA terminal nueva que abras
# para trabajar con este proyecto.

source install/setup.bash

# ------------------------------------------------------------------
# Paso 4: Lanzar la simulación
# ------------------------------------------------------------------
# Este es el comando final. Inicia Gazebo, carga el mundo del almacén,
# inserta el robot RB_Theron y activa el sistema de control.

ros2 launch rb_theron_description_fortress spawn_robot.launch.py
